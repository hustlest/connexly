Connexly runs on a dark navy canvas by default now — the site should feel like an operations console for a live market, not a brochure. Light "paper" surfaces are reserved for the moments people are reading, filling in, or scanning dense data: forms, listing cards, tables. Everything else lives on navy, with orange doing the one job of pointing at what to do next.

00 — Direction

Reference: promo-tech-store.vercel.app/awwwards

That site sells industrial automation parts — a different market, but the same underlying job as Connexly: a technical, inventory-driven B2B product trying not to feel like a spreadsheet. It's a useful reference for tone, not for color.

What we're borrowing: a dark canvas as the default rather than an accent; an oversized, confident headline that states the value prop in one line; stat callouts placed right under the hero instead of buried in an About page; catalog cards built for scanning and quick action, not browsing; a testimonial grid that reads as evidence, not decoration; and a full-bleed dark band to close the page on a single action. What we're not borrowing: their near-black-and-white palette. Connexly stays navy, blue, orange, machine green, and human cream throughout — the dark-first layout is a structural choice, the color identity doesn't move.

Usage roles on the dark canvas

Accent — Orange

Primary CTAs, active/pending status, the logo's signature dot motif. On navy it's the only warm note in the frame — use once per view as a focal point.

Machine — Green

Automated / system-generated content on dark surfaces: API responses, transfer-log status, block metadata. Signals "the system did this."

Human — Cream

Body copy and light-surface cards where a broker or client is reading — forms, listing cards, bios. The one place the canvas turns light on purpose.

02 — Typography

Helvetica, four ways

The wordmark is the only serif moment in the system. Everything else — UI, body copy, data — is set in Helvetica across four roles: Light for reading, Regular for UI, Oblique for system/inline emphasis, Bold for structure. Nothing sits outside these four.

03 — Logo usage

Wordmark

The three orange dots stand in for binary — the join between the "on" and "off" of a transfer. Never recolor them, separate them from the wordmark, or reproduce the mark below 24px tall on screen. On the dark-first site, the light-background lockup is now the exception, not the rule.

Default — on navy #001A3F
On light surfaces — #FBFAF8

Clearspace

Minimum clearspace equals the height of the lowercase "c" on all sides. Nothing — text, edges, other marks — enters that zone.

Do
  • Default to the mark on navy across the site
  • Keep the orange dots exactly as supplied
  • Scale proportionally from the master file
Don't
  • Place on busy photography or mid-tone backgrounds
  • Recolor the wordmark or dots to match a section accent
  • Stretch, skew, or add drop shadows / effects
04 — Spacing & grid

An 8px system
